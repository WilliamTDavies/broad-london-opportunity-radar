# Contributing

Use Python 3.12+, create a focused branch, and run all commands in the README before opening a pull request. New sources require an official URL, authority classification, saved fixture and parser test. Never commit copied subscriber data, raw credentials or large unbounded responses.

Classification changes need positive and negative regression tests. Preserve eligibility/relevance separation and exact evidence. Avoid adding a role because an employer is prestigious. For corrections, cite the official wording and use a manual override only when a deterministic rule cannot safely express it.

Generated files may be rebuilt, but do not rewrite observation times or JSON merely because a scan produced no semantic change. Keep closed/public retention and source-health semantics intact.
